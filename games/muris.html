Muris

Submission to Micro Jam 044
Based on themes Space and Mouse input only.

Links:  Itch page

Mouse input only. Again.. So this time I made a game where you control a mouse controlling a spaceship.

I think if I were to continue work on this, I’d focus on integrating the inside-spaceship (mouse) zone and outside-spaceship (space) zones better. As it was for the jam, it was really clunky to coordinate between the two, so I ended up with two separate things that didn’t really interact :/

It was kind of fun to do dialogue (first time!), and I did end up reimplementing the wiring system I came up with for this one in Goop Snake!
