EMMA'S PAGE / Posts / on Avoiding Microsoft products

27 October 2025

What?

When this all started, GitHub* and VSCode had both been significant parts of my workflow. I’m increasingly disturbed though to be relying on any Microsoft products. At first it was just because of how much they started pushing AI (both products I mentioned have BLARING advertisements on their landing pages for Copilot, pictured below). Since starting to cut them out though, I’ve started to find other motivations to escape, and increasingly I wish I had realized what was happening sooner.

*did you realize that GitHub is camel-cased? I hadn’t 😲

How?

Replacing VSCode

In place of VSCode, I now happily use Zed. This change took a slight adjustment at first, but Zed feels a lot closer to the command line and actually having to configure the linting and stuff myself has given me a deeper understanding of how the IDE works in the first place. Instead of hiding the complexity, it presents it and clarifies it. It’s been changing how I interact with code, much for the better.

Also Zed has this fancy feature where it displays stuff like -> or === or != or <= or => like this:

Smooth as fuck!

Replacing GitHub

This one is trickier to cut out… Probably because GitHub serves multiple purposes. I’ll go over each one individually.

Purpose 1. Git remotes

For this, I’d like to switch to self-hosting. Eventually it might make sense to back up some of the data further away too, maybe if I can find/afford hosting that works well for the purpose.

Purpose 2. Webhosting

I’ll probably keep using GitHub pages for a bit until I figure it out.. but I already paid for some Namecheap hosting so I’ll be trying that first. I’m thinking that once it runs out (and hikes from the first-year “get-you-to-lock-yourself-in” to $50/year >.>) I’ll switch to something cheaper like Hetzner, and at that point hopefully it will be more of just a backup to machines that I own. But who knows! I don’t ;-;

Purpose 3. Open Source

The last thing is something that I’ll unfortunately probably have to keep using Git for: contributing to open source projects. Ideally they’d all move away from GitHub too, but I think I’m ok with using it, for that specific purpose. It’s not like I’ve actually made any open source contributions before anyway though, so this isn’t an immediate problem. It’s just something I anticipate running into as I continue to come back to life.

Conclusion

A lot of common tools are out to get you! They want you to not think, to not understand, to consume instead of produce. AI is the shining exemplar of that, but increasingly it seems like VSCode has a similar issue (of hiding its technical details and obscuring what it’s actually doing). And, while GitHub is good As Of Writing, it definitely has similar problems, mostly only in its desktop applications at the moment. I see that divide deepening in the future, the interfaces getting more opaque, further from what they’re actually doing, and more proprietary (open source or no).

Anyway that’s all I have to say on the topic for now. I’m pretty scared what Microsoft Owning GitHub will do to open source as a whole.. But I’ll just truck forth, on my own path, and try not to worry about what I can’t control.

See ya 🙂✨
